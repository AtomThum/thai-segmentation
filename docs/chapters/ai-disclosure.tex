\chapter{การใช้ปัญญาประดิษฐ์ในกระบวนการพัฒนา}

ผู้พัฒนาชุดคำสั่งได้พัฒนาส่วนต่อประสานระหว่าง \lualatexlogo และขั้นตอนวิธี
\texttt{newmm} เอง ได้เขียนคู่มือการใช้งานทั้งภาษาไทยและภาษาอังกฤษเอง แต่ใช้
Claude Opus 5.5 เพื่อช่วยแปลขั้นตอนวิธี \texttt{newmm} จากโปรแกรม
\texttt{PyThaiNLP} ให้เป็นภาษา Lua และได้ใช้เพื่อแก้ไวยากรณ์ภาษาอังกฤษ
